# Glossary

| Термин | Значение |
|---|---|
| Обращение (Case) | Основная рабочая сущность, связанная с текстом, файлами, статусом и организацией/шаблоном |
| Шаблон (Template) | Текстовая заготовка с переменными для генерации обращения |
| Организация (Institution) | Адресат/канал подачи обращения, включая лимиты и URL |
| Visibility | Доступность directory-объекта (`public` или `private`) |
| Owner | Пользователь-владелец записи (`owner_user_id`) |
| Soft-delete | Пометка записи как удаленной (`deleted_at`, `deleted_by_user_id`) без физического удаления |
| Purge | Физическое удаление ранее soft-deleted записей админом |
| FSM snapshot | Состояние кейса в Redis (файлы/текст/пакет/ошибки) |
| Guest mode | Режим без токена: просмотр только публичных directory-данных |
| `admin_view` | Админ с правом просмотра админских разделов без destructive действий |
| `admin_full` | Админ с полным доступом (роли, restore/purge, backup mutate) |
