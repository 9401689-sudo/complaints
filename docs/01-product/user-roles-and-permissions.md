# User Roles And Permissions

Текущие роли backend: `user`, `admin_view`, `admin_full`.
Guest-поведение реализовано во frontend (без токена).

| Действие | Guest | User | Admin View | Admin Full |
|---|---:|---:|---:|---:|
| Просмотр публичных организаций/шаблонов | Да | Да | Да | Да |
| Просмотр обращений | Нет | Свои | Все | Все |
| Создание/изменение своих обращений | Нет | Да | Да | Да |
| Создание private организаций/шаблонов | Нет | Да | Да | Да |
| Переключение public/private/owner у directory | Нет | Нет | Нет | Да |
| Избранное (templates/institutions) | Нет | Да | Да | Да |
| Просмотр списка пользователей | Нет | Нет | Да | Да |
| Изменение ролей пользователей | Нет | Нет | Нет | Да |
| Удаление пользователей | Нет | Нет | Нет | Да |
| Просмотр помеченных к удалению | Нет | Нет | Да | Да |
| Restore/purge удаленных сущностей | Нет | Нет | Нет | Да |
| Просмотр резервных копий | Нет | Нет | Да | Да |
| Создание/удаление/восстановление backup | Нет | Нет | Нет | Да |
