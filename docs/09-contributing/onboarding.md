# Onboarding

## Day 1 checklist

1. Read:
   - `docs/00-overview/*`
   - `docs/03-codebase-map/source-of-truth-and-legacy-folders.md`
2. Confirm working branch and clean status.
3. Start backend and run health checks.
4. Validate browser access and auth flow.
5. Walk through one end-to-end case lifecycle.

## Day 2 checklist

1. Review module maps (frontend/backend).
2. Review role matrix and admin flows.
3. Reproduce backup create/list flow in non-production context.
4. Pick first bounded task with explicit verification checklist.
